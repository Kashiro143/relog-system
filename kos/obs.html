🧩 Installer dans OBS

Le K-OS ajoute lui-même ses sources dans tes scènes OBS, au bon format. Tu peux revenir ici à tout moment pour vérifier ou réparer.

1 Relier cette page à OBS

  1. Dans OBS : Outils → Paramètres du serveur WebSocket.
  2. Coche Activer le serveur WebSocket, puis Appliquer.
  3. Clique Afficher les infos de connexion et copie le mot de passe du serveur.
  4. Colle-le ci-dessous. Il reste dans ce navigateur, il n'est envoyé nulle part ailleurs qu'à ton OBS.

Astuce : le plus fiable est d'ouvrir cette page dans OBS, en dock (étape 3, ligne « K-OS Installer »). Dans Chrome, accepte la demande d'accès au réseau local si elle apparaît.

2 Choisir où afficher le K-OS

Re:log : ce que les autres t'envoient (GIF, salons, signaux, watch-party). À mettre sur toutes les scènes où tu veux les recevoir. Module : ton module du moment (ex. équipe PokeMMO), seulement là où tu le veux.

3 Ajouter les panneaux (docks) dans OBS

  1. Dans OBS : Docks → Docks de navigateur personnalisés…
  2. Pour chaque ligne ci-dessous : un nom à gauche, l'adresse copiée à droite, puis Appliquer.
  3. Connecte-toi une fois avec Google dans un dock : les autres suivent.
